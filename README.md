# VideoCut — 本地视频裁剪工具

一个纯前端的本地视频裁剪工具，所有处理均在浏览器中完成，视频不会上传到任何服务器。

## 功能特性

- **本地处理**：全程在浏览器端完成，无需上传，保护隐私
- **无损裁剪**：基于 MP4Box.js 解析 MP4 box 结构，按关键帧对齐截取，保持原始画质
- **可视化时间轴**：拖拽起止手柄选择裁剪区间，支持整体平移选区
- **精确时间输入**：开始 / 时长 / 结束三个时间框可直接输入（支持 `mm:ss` 或纯秒数）
- **快速设点**：旗帜按钮一键将起点 / 终点设为当前播放位置
- **键盘快捷键**：支持播放控制、跳转、音量调节
- **深色主题 UI**：现代化暗色界面

## 技术栈

- React 18 + TypeScript
- Vite 6 构建
- Tailwind CSS 3 样式
- Zustand 状态管理
- MP4Box.js 视频解析与无损裁剪
- lucide-react 图标

## 快速开始

### 环境要求

- Node.js >= 18
- pnpm（推荐）或 npm

### 安装依赖

```bash
pnpm install
```

### 启动开发服务器

```bash
pnpm dev
```

访问 http://localhost:5173

### 构建生产版本

```bash
pnpm build
```

构建产物输出到 `dist/` 目录。

### 预览生产构建

```bash
pnpm preview
```

### 类型检查

```bash
pnpm check
```

## 打包为桌面应用（macOS）

将项目打包为可双击运行的 `.app` 应用：

```bash
pnpm package:app
```

产物位于 `dist-app/VideoCut.app`，双击即可一键运行。

**工作原理**：应用启动时会在本地启动一个轻量 HTTP 服务器（基于 Node.js 内置模块，无需额外依赖），然后在默认浏览器中打开应用页面。视频处理全程在本地浏览器中完成，不会上传到任何服务器。

**运行要求**：系统需已安装 Node.js（项目开发环境已具备）。

## 使用说明

1. **上传视频**：点击或拖放 MP4 文件到上传区域
2. **选择裁剪区间**：
   - 拖拽时间轴上的左右手柄调整起止位置
   - 或直接在下方输入框中输入开始 / 时长 / 结束时间
   - 播放视频后，点击旗帜按钮可将起点 / 终点快速设为当前播放位置
3. **导出视频**：点击「导出视频」按钮，裁剪后的视频会自动下载

## 键盘快捷键

| 按键 | 功能 |
|------|------|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 暂停时每次 ±1 秒，播放时每次 ±10 秒 |
| `↑` / `↓` | 音量 ±10% |

> 焦点在输入框中时快捷键不会响应。

## 无损裁剪说明

- **仅支持 MP4 格式**：工具使用 MP4Box.js 直接解析和修改 MP4 的 box 结构，实现无损裁剪
- **关键帧对齐**：裁剪起点会自动对齐到最近的关键帧（I 帧），以保证输出文件可正常解码
- **多轨支持**：自动处理视频轨与音频轨的去交错与重排，修正 `stco` 偏移
- **画质无损**：不重新编码，保留原始编码参数、分辨率、码率
